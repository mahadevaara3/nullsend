Don't trust us. Verify.

"Private" is easy to claim. These are four ways to check it, from quickest to most thorough.

Watch the meter

The pill at the top counts bytes uploaded and requests to other sites. Use a tool and watch it stay at zero.

Pull the plug

Open a tool once, then turn off Wi-Fi. It keeps working, because there is no server doing the work.

Read the policy

The page's Content-Security-Policy allows connections only to this site. The browser itself blocks anything else.

Read the code

The whole project is open source under AGPL-3.0, so any copy someone hosts must publish its code too.
